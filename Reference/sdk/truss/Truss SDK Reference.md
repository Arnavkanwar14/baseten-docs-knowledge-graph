> Python SDK for deploying and managing models with Truss.

The Truss Python SDK deploys and manages models on Baseten from Python.

## Functions

* [[truss.login|`truss.login`]]: authenticate with an API key.
* [[truss.push|`truss.push`]]: deploy a Truss model.
* [[truss.load|`truss.load`]]: get a handle to a local Truss.
* [[truss.whoami|`truss.whoami`]]: show the authenticated account.

## Objects

* [[ModelDeployment|`ModelDeployment`]]: returned by `truss.push()`.
